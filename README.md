# homebrew-tap

Homebrew tap for [Tom-xyz](https://github.com/Tom-xyz) tools.

## Install

```bash
brew tap tom-xyz/tap
brew install <formula>
```

Or in one command:

```bash
brew install tom-xyz/tap/<formula>
```

## Tools

| Formula | Description |
|---------|-------------|
| [fflogo](https://github.com/Tom-xyz/ff-logo-picker) | Interactive picker for fastfetch ASCII logos — fuzzy-search, live-preview, one-keystroke apply |
| [pingx](https://github.com/Tom-xyz/pingx) | Full-screen TUI ping monitor with auto-reconnect and WAN failover detection |
| [emporia-monitor](https://github.com/Tom-xyz/emporia-energy-monitor) | Real-time, liquid-glass energy dashboard for Emporia Vue |
