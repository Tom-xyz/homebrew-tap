# homebrew-tap

Homebrew tap for [Tom-xyz](https://github.com/Tom-xyz) tools.

## Install

```bash
brew tap tom-xyz/tap
brew install pingx
```

Or in one command:

```bash
brew install tom-xyz/tap/pingx
```

## Tools

| Formula | Description |
|---------|-------------|
| [pingx](https://github.com/Tom-xyz/pingx) | Full-screen TUI ping monitor with auto-reconnect and WAN failover detection |
